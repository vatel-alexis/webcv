# Alexis Vatel – CV website

Personal website of Alexis Vatel, Data & AI Product Owner.

Static HTML/CSS, no build step.

- `index.html`: the whole page (styles inline)
- `assets/`: photo, logo, Veris Assets logo and Northwind demo photo, favicon

## Work locally

Open the folder in VS Code and start the **Live Server** extension on `index.html`.

## Publish

Settings → Pages → Deploy from branch → `main` / root.
